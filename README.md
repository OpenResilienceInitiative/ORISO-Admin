# ORISO Admin

## Overview

Admin dashboard application for managing the Online Beratung platform.

## Quick Start

### Build Docker Image

```bash
cd /home/caritas/Desktop/online-beratung/caritas-workspace/ORISO-Admin
docker build -t caritas-admin:latest .
sudo k3s ctr images import <(docker save caritas-admin:latest)
```

### Run Locally (Development)

```bash
cd /home/caritas/Desktop/online-beratung/caritas-workspace/ORISO-Admin
npm install
npm run dev
```

### Environment Configuration

Copy `.env.example` to `.env` and configure:

```bash
# API Configuration
VITE_API_URL=http://91.99.219.182

# Keycloak Configuration
VITE_KEYCLOAK_URL=http://91.99.219.182:8080
VITE_KEYCLOAK_REALM=online-beratung
VITE_KEYCLOAK_CLIENT_ID=admin-app
```

## Kubernetes Deployment

```bash
kubectl apply -f /home/caritas/Desktop/online-beratung/kubernetes-complete/03-frontend-admin.yaml
```

## Important Notes

-   Uses Docker image: `caritas-admin:latest`
-   Runs on port: `3000`
-   Requires admin-level Keycloak credentials
-   Environment variables are baked into the Docker image during build

## Dependencies

-   Node.js 18+
-   React 18
-   Vite 4
-   Keycloak JS adapter

## Access

-   Admin panel accessible at: `http://91.99.219.182:3000`
-   Login with Keycloak admin credentials

## Knowledge Graph

The generated Understand-Anything graph (`knowledge-graph.json`, `meta.json`, `fingerprints.json`) is not committed to this repository. ORISO-Docs builds it and publishes it as a signed release asset. The hand-written summaries in `.understand-anything/*.md` stay here.

-   Browse it: [understand.oriso.org](https://understand.oriso.org/)
-   Fetch it locally:

```bash
mkdir -p /tmp/ua && cd /tmp/ua
curl -fsSLO https://github.com/OpenResilienceInitiative/ORISO-Docs/releases/download/ua-graph-latest/ORISO-Admin.tar.gz
gh attestation verify ORISO-Admin.tar.gz --repo OpenResilienceInitiative/ORISO-Docs \
  --signer-workflow OpenResilienceInitiative/ORISO-Docs/.github/workflows/ua-graph-refresh.yml
tar -xzf ORISO-Admin.tar.gz   # unpacks to ORISO-Admin/.understand-anything/
```

Before relying on it, compare `gitCommitHash` in `meta.json` with `origin/dev`.

To open the fetched graph in a local dashboard:

```bash
cd "$UNDERSTAND_ANYTHING_DASHBOARD"
GRAPH_DIR=/tmp/ua/ORISO-Admin pnpm exec vite --host 127.0.0.1
```

Set `UNDERSTAND_ANYTHING_DASHBOARD` to your local Understand-Anything `packages/dashboard` directory before running the command. This keeps the README portable and avoids hardcoded local paths.

No agent is required to generate the token. The token is generated by the dashboard server when you start it in your own terminal. It is not stored in `.env`, `package.json`, or the repository.

After running the dashboard command, copy the full URL printed in the same terminal. Look for the line that starts with `Dashboard URL`, for example:

```bash
http://127.0.0.1:5173/?token=<token>
```

Open that full URL including `?token=...`. If the token is missing, the dashboard will show an access-token gate instead of the graph.

Do not use the ORISO-Admin app URL, such as `http://127.0.0.1:9000/admin/login`, for the graph dashboard. That URL opens the admin application login page and will not print or accept the Understand-Anything graph token.

If the command prints a URL like `http://127.0.0.1:9000/admin`, Vite is still running ORISO-Admin instead of the graph dashboard. Check the dashboard path before starting Vite:

```bash
echo "$UNDERSTAND_ANYTHING_DASHBOARD"
test -f "$UNDERSTAND_ANYTHING_DASHBOARD/package.json"
```

Then run `cd "$UNDERSTAND_ANYTHING_DASHBOARD"` again and confirm `pwd` points to the Understand-Anything `packages/dashboard` directory, not this ORISO-Admin repository.

If the dashboard opens but shows `Invalid knowledge graph: Missing or invalid project metadata`, stop it with `Ctrl+C` and restart it with `GRAPH_DIR` pointing at the unpacked `/tmp/ua/ORISO-Admin` directory.

Generated graph documentation lives under `.understand-anything/`:

-   `.understand-anything/README.md`
-   `.understand-anything/ARCHITECTURE.md`
-   `.understand-anything/ONBOARDING.md`
-   `.understand-anything/ORISO-ECOSYSTEM.md`
-   `.understand-anything/FINDINGS.md`
-   `.understand-anything/DEPENDENCY-AUDIT.md`
-   `.understand-anything/visuals/`

Local regeneration (`/understand . --full`) still works, but its output is git-ignored. Do not commit it; the published graph is the shared one.
